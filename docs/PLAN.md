# План работ

Цель: настольное приложение «Своя Игра» для macOS, Windows и Linux на Tauri 2 поверх
текущего Vue-фронтенда. Быстрое, лёгкое, работает офлайн. Сборка и выпуск — в GitHub
Actions, распространение — через GitHub Releases.

Каждая фаза закрывается только когда зелёные `typecheck`, `lint`, `test` и `build`
(а с фазы 2 — ещё и `tauri build` в CI на всех трёх ОС).

## Решения

- **Tauri 2, а не Electron/Wails/Flutter.** Фронтенд остаётся как есть, нативная часть —
  готовые плагины (fs, dialog, updater, window-state, deep-link/ассоциации файлов).
- **Приложение — только десктоп.** Портативный HTML и скрипты `start.*` / `scripts/launch*`
  удаляются в фазе 7, когда десктопная сборка их полностью заменит.
- **GitHub Pages — промо-сайт** (`site/`, отдельная Vite-сборка в том же репозитории)
  со ссылками на установщики из последнего релиза.
- **Библиотека игр — IndexedDB внутри WebView, медиа — Blob в отдельном хранилище.**
  Данные WebView живут в каталоге приложения и не вычищаются браузерными политиками.
  Файлы на диске — это `.gamezip` для импорта/экспорта и «Открыть с помощью».
- **YouTube через локальный мост.** Под `tauri://` YouTube отвечает ошибкой 153 (нет
  http-referrer). Приложение встраивает страницу `http://127.0.0.1:<случайный порт>/youtube`
  из встроенного в бинарник сервера, она встраивает плеер и пересылает сообщения iframe API.
  Ассеты приложения и IPC остаются на `tauri://`, фиксированный порт не нужен.
  `tauri-plugin-localhost` отвергнут: он открывает все ассеты на фиксированном порту,
  а IndexedDB оказалась бы привязана к этому порту.
- **UI-кит — shadcn-vue** (Reka UI + Tailwind v4), перекрашенный в сине-золотую тему.
  Игровые элементы (доска, слайды, ячейки) остаются своими.

## Открытые вопросы

- Аккаунт Apple Developer ($99/год) для нотаризации — без него macOS при первом запуске
  требует подтверждения в «Системных настройках».
- Сертификат подписи для Windows — без него SmartScreen показывает предупреждение.
